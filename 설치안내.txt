회복 버튼 제거판 — Windows 모드 v1.5.2 / Android v0.2.0

유지한 기능
- 원본 실신 기능 활성화
- 행동력 회복/고정, 표정 잠금과 하트눈 제어
- 호감도 슬라이더와 라이벌 제어/오늘 밤 수면
제거한 기능은 [회복~ 아프지마~] 탭과 전용 코드뿐입니다.
행동력 회복 버튼은 기존 행동력 기능에 포함되므로 유지합니다.
실신 기준과 CG 표정은 직전 활성화 버전의 기존 게임 규칙 그대로입니다.

Android 설치
1. Gensokyo-Mod-Android-v0.2.0.apk를 휴대폰에 다운로드합니다.
2. APK를 눌러 설치합니다. 설치 출처 허용을 요청하면 해당 브라우저/파일 앱에
   [이 출처 허용/알 수 없는 앱 설치 허용]을 적용하고 설치를 계속합니다.
3. 앱 목록의 [환상향 MOD]를 실행합니다.
4. 가로 화면 오른쪽 위 [MOD] 버튼으로 두 기능 탭을 엽니다.
본게임, 한국어 패치와 유지할 모드를 앱 안에 포함했습니다.
Windows EXE/PCK를 휴대폰에 별도로 복사하지 않아도 됩니다.
64비트 ARM64 Android 7.0 이상용입니다.

이전 Android v0.1.0이 설치되어 있으면 앱을 삭제하지 말고 업데이트 설치하세요.
같은 앱 ID/서명키를 유지하고 설치 버전 번호를 2로 올렸습니다.
실제 Android 기기에서의 업데이트/저장 유지 동작은 미검증입니다.
앱 삭제나 데이터 삭제는 내부 저장 파일을 지울 수 있습니다.

Windows 설치
게임을 종료하고 기존 모드 PCK는 별도 보관한 뒤,
ふしだら幻想郷_patch_1.04-1.05.9.9.pck를 게임 EXE 옆에 넣고 재실행합니다.
본래 EXE와 원래 한국어 패치는 유지합니다. 모드창은 F3으로 엽니다.
Windows용 ZIP은 APK 설치에 사용하지 않습니다.

검증 범위
Windows PCK: 실신/구성 확인 66개, 기존 모드 996개, 재시작 저장 복원 38개 통과.
Android APK에서 꺼낸 리소스: 실신/구성 66개, 기존 모드 996개,
재시작 저장 복원 38개, 터치/모바일 UI 28개 통과.
APK 서명, 이전 앱과의 서명 동일성, 버전 번호, ARM64 ABI,
16KB 라이브러리 정렬, ZIP CRC와 데이터 무결성을 확인했습니다.
기능 검사는 Linux Godot 엔진에서 수행했습니다.
실제 Android 기기/에뮬레이터 설치·실행 및 Windows 실기기는 미검증입니다.
기기별 GPU 렌더링·소리·발열·터치 반응도 확인이 필요합니다.
