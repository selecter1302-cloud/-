# 나라나 에디션 v0.12.6

나라나 에디션 0.12.6 internal-r1

ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요. 앱을 삭제하지 마세요.
같은 패키지·서명·저장 경로, versionCode 37, ARM64, Android 7.0 이상.

새 MOD 탭: 표정 집합
1. MOD → 표정 집합 → 현재 화면 가져오기.
   인물·일반/H씬·체위·상대·관계를 고릅니다. 공개/비밀 연인도 따로 저장합니다.
2. 같은 조건에서 대화하기만 반복해도 계속 바꾸려면 맨 위 '전체 →'의 집합 편집을 누르세요.
   특정 원래 표정에만 연결하려면 그 표정 그림 옆의 집합 편집을 누르세요.
3. 새 집합에는 원래 표정이 기본 후보로 들어 있습니다. 체크를 해제하거나 다시 넣을 수 있습니다.
   원하는 후보를 최대 10개 선택하세요(원래 표정 포함). 선택 순서대로 행동마다 교대합니다.
   그림을 누르면 실제 장면과 합친 확대 미리보기가 열립니다. 집합 저장을 눌러야 반영합니다.
4. 세부 조건에서 체크한 항목만 검사합니다. 새 집합의 기본 조건은 현재 기분 구간과 인물이 있는 장소입니다.
   기분·호감도·성욕·취기·장면 게이지는 범위로 지정합니다. 최소와 최대가 같으면 정확히 그 값만 적용합니다.
   장소·시간대·옷차림·직전 행동·장면 단계·날씨·동석 인물 구성·단둘이·수면·최면·작업 중도 선택합니다.
   조건을 모두 해제하면 인물·관계·상대·화면/체위·원래 표정만 구분합니다.
5. 특정 원래 표정 규칙이 전체 규칙보다 우선하고, 같은 원래 표정이면 세부 조건이 더 구체적인 규칙을 우선합니다.
   대체 안 함은 해당 조건의 원래 표정을 유지합니다. 취소는 저장을 바꾸지 않습니다.
6. 삽입-고정 수술♡과 표정 집합은 같은 저장 목록입니다.
   수술♡에서 하나를 확정하면 같은 조건의 한 개짜리 집합이 되고,
   여러 개짜리는 수술♡ 목록의 미리보기·수정에서도 집합 편집기로 열립니다.
7. 수술♡·집합 적용 OFF는 두 기능을 함께 끄되 목록을 유지합니다. 개별 항목도 OFF할 수 있습니다.
   새끼버튼 표시 OFF는 그림 위의 작은 버튼만 숨깁니다.
8. 기존 항상 고정이 켜져 있으면 우선합니다. 표정 집합 탭의 기존 항상 고정 해제로 해제할 수 있습니다.
   제외/OFF 표정은 교대 후보에서 건너뜁니다. 전부 쓸 수 없으면 인물을 숨기지 않고 안전한 원래 그림을 유지합니다.
   후배위는 제공된 그림에 분리된 얼굴층이 없어 원본을 유지합니다.
9. 설정과 선택 순서는 앱 재시작·세이브 변경 후에도 유지합니다. 세이브 내보내기/복원에 포함합니다.
   단순 화면 갱신·편집창 열기·불러오기는 교대 순서를 진행시키지 않습니다.

원본 반응 애니메이션 점검
미소·수줍음 등은 튀어오름, 새침한 반응은 좌우 흔들림입니다. 모든 대화가 항상 튀지는 않습니다.
게임 설정의 효과가 일반/줄임이면 가벼운 반응이 나오며, 없음이면 나오지 않습니다.
연타 중 교체된 수치/아이콘 표시의 애니메이션이 남던 경로도 정리했습니다.

최종 APK 리소스를 Linux Godot에서 실행해 검사했습니다.
Android 실기기·에뮬레이터 설치 실행은 미검증입니다.

대형 ZIP은 Git LFS로 보관합니다.
