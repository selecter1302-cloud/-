# 나라나 에디션 v0.11.3

나라나 에디션 0.11.3 internal-r1

ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요.
같은 패키지·서명·저장 경로 / versionCode 29 / ARM64 / Android 7.0 이상.
세이브를 유지하려면 기존 앱을 삭제하지 마세요.

밤의 공동 식사 → 교류 → 규칙 제안.
투표 후 가결·부결·동률과 득표수를 결과 창에서 확인합니다.
목록 → 주인공 → 능력과 상태 아래 ‘집안 규칙’에서 현재 규칙과 기간을 확인합니다.
다른 인물의 표는 주인공 선택 전에 확정하며, 개별 표는 화면에 공개하지 않습니다.
버튼 이름을 ‘규칙 제안’, ‘부추기기’로 정리했습니다.
‘관전 부르기’를 주요 행동 버튼에서 분리해 종료 버튼 아래에 배치했습니다.
두 사람 장면의 짧은 반응 뒤에는 사용자가 제공한 비노골적인 지문 예시를 연결합니다.
제시한 짧은 확인 대사를 기존 조건으로 성립한 장면에서 각자 한 번 표시합니다.
업데이트 후 적발 이벤트에서 해당 히로인 선택을 고르면, 그 히로인의 다른 관계 수용 검사를 자발적 참여자 사이에서 완화합니다.
기존 세이브는 MOD → 추가 상황 → 각 인물의 ‘이전 세이브: 적발 때 이 인물을 선택했음’에서 이미 마친 선택을 반영할 수 있습니다. 사랑에 굴복한 상태는 연인과 함께 선택할 수 있습니다. 협박 중은 예외에서 제외합니다. 잠·취기 등 개별 참여 제한은 유지합니다.
표정과 직접 선택한 외형의 공통 설정 유지는 이전 버전과 같습니다.

APK 리소스를 Linux Godot/X11에서 실행해 검사했습니다.
안드로이드 실기기·에뮬레이터에서 설치 실행한 결과는 아닙니다.

대형 ZIP은 Git LFS로 보관합니다.
