# Gensokyo Dialogue Editor v0.3.0

[새 짧은 대사·지문 검토본 다운로드](https://github.com/selecter1302-cloud/-/raw/refs/heads/gensokyo-dialogue-editor-v0.3.0/Gensokyo-Dialogue-Editor-v0.3.0.zip)

APK의 이름·색상·출력 코드를 다시 확인해 새로 작성한 검토본입니다. APK에는 적용하지 않았습니다.

- 주인공 행동 접두문 제거.
- 짧은 발화 → 히로인 행동 한 문장, 또는 행동 지문만 출력.
- 본문 1,232개: 대사+지문 1,064개 / 지문만 168개.
- 템플릿 중간 길이 55자, 최대 69자. 이름을 치환하면 표시 길이는 달라집니다.
- 원본에 맞춘 발화자 성명·짧은 지문 이름·캐릭터 색·회색 지문·흰색 무대사 본문 미리보기.
- 커스텀 주인공·라이벌 이름과 조사 표식 미리보기.
- **화면 오른쪽 고정 저장 버튼**. 모바일에서는 오른쪽 아래 고정.
- v0.2 수정 JSON을 새 본문 옆의 이전 수정문 참고로 불러와 수정 내용·결과·메모를 보존.

ZIP을 풀고 `review/index.html`을 브라우저로 여세요. 본문을 수정한 뒤 오른쪽 ‘수정본 저장(JSON)’으로 받은 파일을 채팅에 첨부하면 됩니다.
HTML 자체에 수정 내용이 저장되는 것은 아니므로 JSON 파일을 보관하세요.

## 검증

원본에서 추출한 이름·색상 함수를 Godot 4.6.3에서 목 이름 데이터로 실행해 출력 규칙을 확인했습니다. 게임 전체 실행 검사가 아닙니다.
실제 Chromium에서 색상·이름·조사·여러 줄 미리보기, 오른쪽 저장 버튼, v0.2 수정본 보존, JSON 저장·복원을 검사했습니다.
관리형 Chromium은 file://을 차단하므로 브라우저 검사는 임시 로컬 HTTP로 진행했습니다. 편집 HTML 자체는 외부 서버 호출이나 의존 파일 없이 구성했습니다.
분기 참조 모델과 편집기 검사 15개, 별도 폴더 재생성 및 7개 결과 파일 일치 검사를 통과했습니다.

EXE·APK는 포함하지 않습니다. APK 패치·재빌드·서명·Android 기기 실행은 하지 않았습니다.
기존 배포 브랜치를 덮어쓰지 않는 새 버전입니다. 체크섬은 SHA256SUMS.txt, 상세 검증 기록은 VALIDATION.json에 있습니다.
