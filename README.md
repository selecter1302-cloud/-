## 세이브 목록 스크롤 수정

- 저장과 불러오기 목록 모두 슬롯 위를 손가락으로 위아래로 밀어 스크롤.
- 터치 가능 여부에 대한 엔진 판정에 의존하지 않고 실제 터치 이벤트를 직접 처리.
- 손을 떼면 짧게 이어지는 관성 스크롤. 움직이는 목록을 탭하면 우선 멈추고 슬롯을 선택하지 않음.
- 드래그, 멀티터치, 취소된 터치와 앱 포커스 상실은 슬롯 실행을 차단.
- Godot가 원본 터치보다 먼저 전달하는 가상 마우스 입력을 중복 처리하지 않음.
- 세이브칸 길게 누르기에 연타 기능을 적용하지 않음. 손을 떼는 일반 탭으로 한 번만 저장/불러오기.
- 보조 세로 스크롤바의 폭도 기준 화면에서 36px로 확대.
- 마우스 드래그와 휠도 지원. 페이지를 바꾸거나 창을 다시 열면 스크롤을 초기화.

관계 표시와 기존 MOD 기능은 유지했습니다.

## 검증

완성 APK의 리소스를 추출해 Linux Godot 4.6.3으로 검사했습니다.
1280×720과 2400×1080에서 손가락 스와이프, 관성, 오터치 방지, 실제 탭 저장/불러오기를 검사했습니다.
기존 MOD, 입력, 저장, 재시작 복원 회귀 검사를 포함해 총 2,588개 검사 통과.
APK 서명과 동일 인증서, versionCode, ARM64, 16KB 정렬, ZIP CRC 및 데이터 무결성 검사 통과.
실제 Android 기기 설치·실행은 미검증입니다.
