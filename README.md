# 로컬 대사 검토 도구 v1.0.0

ZIP을 풀고 **DialogueReviewer.html**을 Edge/Chrome으로 연 다음, 게임 EXE와 PCK를 함께 선택하고 **읽기 시작**을 누르세요.

- 원문 전체 표시, 검색, 원문/번역문과 조건 후보 연결
- 검토자 판정과 사유 기록, TXT/CSV 및 기록 백업 저장
- 원본 해시, 읽기 실패와 미해석 파일 목록
- 선택 파일은 PC에서만 처리하며 게임 원문은 배포 파일에 포함하지 않습니다.

문자열 수는 대사 문장 수와 다릅니다. 이미지·음성·네이티브 영역·동적 조합은 별도 검토해야 합니다. 상세 사용법과 검증 범위는 ZIP 안의 안내 파일을 확인하세요. Windows 실기기는 미검증입니다.
