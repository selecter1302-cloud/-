이번 1.05.9 → 1.06.3 비교 자료가 포함되어 있어 게임 EXE나 PCK를 다시 선택할 필요가 없습니다.

- 조건·표정 변경과 한국어 번역 변경도 별도 필터로 열람.
- 원문·한국어의 변경 전후, 파일 위치, 조건 표시. 상세와 내보내기에는 전문 보존.
- 캐릭터·문장·조건·이벤트·검토 메모·ID 검색.
- 검토 판정과 메모 자동 저장, JSON 백업/복원.
- 추가 대사 전체 TXT, 현재 검색 결과 전체 TXT/CSV 저장.
- 원본 PCK의 SHA-256 대조. 게임·PCK 파일 수정과 외부 전송 없음.
- 독립 HTML 대체판도 포함. 최신 Edge/Chrome에서 사용 가능.

단어·내용에 따른 마스킹은 하지 않습니다. 추가/수정 판정은 내용·조건 대조 기준이며 고유 문장 ID 없는 완전 교체는 수정 또는 추가·삭제로 표시될 수 있습니다.
이미지·음성·실행 중 동적 조합은 별도 검토 대상입니다. 자세한 범위와 사용법은 ZIP 안의 사용안내.txt를 확인하세요.

원문 위치 대조와 실제 데이터 기반 브라우저 검사 33개, 저장 API 단위 검사, Windows PE64/GUI 및 ZIP 무결성 검증 통과.
Windows EXE는 교차 빌드했으며 같은 서버의 Linux 실행·Chromium 검사를 수행했습니다. 실제 Windows 실행은 미검증입니다.
관리형 검사 브라우저의 file:// 정책으로 독립 HTML은 동일 파일을 HTTP로 제공해 내장 데이터·브라우저 저장 모드 동작을 검사했습니다.
