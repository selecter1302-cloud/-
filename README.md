# Android MOD v0.9.0 — 세이브 백업·복원

[APK 바로 다운로드](https://github.com/selecter1302-cloud/-/raw/refs/heads/gensokyo-android-v0.9.0/Gensokyo-Mod-Android-v0.9.0.apk)

[ZIP 다운로드](https://github.com/selecter1302-cloud/-/raw/refs/heads/gensokyo-android-v0.9.0/Gensokyo-Mod-Android-v0.9.0.zip)

기존 앱 위에 업데이트 설치하세요. 앱을 먼저 삭제하면 내부 저장 파일이 지워질 수 있습니다.
기존 앱과 같은 앱 ID·서명, versionCode 13, ARM64 Android 7.0 이상입니다.

## 세이브를 폰의 파일관리자에서 꺼내기

1. 게임 **설정 → 세이브** 탭을 엽니다.
2. **모든 세이브 백업 ZIP 저장**을 누릅니다.
3. Android 파일 선택창에서 **다운로드** 등 원하는 폴더를 고르고 저장합니다.
4. 폰의 파일관리자에서 `Gensokyo-Saves-날짜.zip`을 복사하거나 공유하면 됩니다.

저장된 일반·퀵·자동 슬롯, 갤러리 기록, 게임 설정, MOD 설정을 함께 담습니다.
현재 진행은 게임 저장 메뉴에서 먼저 저장한 뒤 백업하세요.
ZIP 안에는 `save_1.json` 같은 개별 JSON 파일도 들어 있습니다.

## 복원

**설정 → 세이브 → 백업 ZIP / 세이브 JSON 불러오기**에서 파일을 선택하세요.
ZIP은 원래 슬롯 번호로 복원합니다. 개별 JSON은 이 탭에서 지정한 1~100번 슬롯으로 가져옵니다.
교체할 파일 수와 대상 슬롯을 확인한 뒤 복원합니다. 복원 후 타이틀에서 불러오기를 선택하세요.
복원 전 상태도 자동으로 보관하며 **복원 전 상태의 백업 ZIP 저장**으로 꺼낼 수 있습니다.

## 이번 수정

세이브 파일을 Android 시스템 파일 선택창으로 내보내고 가져오는 기능을 추가했습니다.
기존 0.8.0 저장 경로를 유지하여 앱 업데이트 시 기존 저장 파일을 그대로 사용할 수 있습니다.
본판 1.06.3과 기존 MOD, 화면비, 설정 안 MOD 메뉴를 유지했습니다.

## 검증

실제 완성 APK에서 꺼낸 자산으로 일반/와이드 화면의 백업·복원, 잘못된 파일 거부, 복원 실패 시 롤백, 저장 불러오기, 기존 MOD 회귀 검사 총 1,950개 통과.
APK 서명, 기존 인증서 일치, 앱 ID, 버전 증가, ZIP 무결성, ARM64 및 16KB 정렬 확인.
Android 네이티브 문서 선택 및 SAF 파일 접근 경로의 엔진 구현을 확인했습니다.
실제 휴대폰의 파일 선택창을 직접 조작한 검사는 수행하지 못했습니다.
