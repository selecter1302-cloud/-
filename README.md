# Android MOD v0.9.4 — 기본 표정 모드·히로인 사이 친밀도

[APK 바로 다운로드](https://github.com/selecter1302-cloud/-/raw/refs/heads/gensokyo-android-v0.9.4/Gensokyo-Mod-Android-v0.9.4.apk)

Chrome에서 다운로드하고 앱을 삭제하지 않은 채 기존 앱 위에 업데이트 설치하세요.
기존 앱과 같은 패키지·서명이며 versionCode 17, ARM64 Android 7.0 이상입니다.

게임 설정 → MOD 설정 → 행동력·표정에서 캐릭터마다 **기본 표정으로 사용 / 항상 고정**을 선택합니다.
기본 모드는 선택 표정을 평상시 기본값으로 쓰고 대화·행동 반응과 수면·최면·취함·나쁜 기분 등의 상태를 우선합니다.
항상 고정은 기존 동작입니다. 표정 체크를 해제하면 원래 자동 표정으로 돌아갑니다.
기존에 선택한 표정은 유지되며 기존 설정에 모드가 없으면 기본 모드로 전환됩니다. 모드·표정은 재실행 후 유지됩니다.

게임 설정 → MOD 설정 → 호감도·라이벌에서 아래로 스크롤하면 **히로인 사이 친밀도**가 있습니다.
레이무·사쿠야·마리사·사나에의 여섯 조합을 0~100으로 조절합니다.
동그라미를 드래그한 뒤 놓으면 두 방향에 함께 적용됩니다. 게임 저장 시 함께 저장됩니다.
히로인끼리의 별도 방향별 호감도는 없으며, 플레이어·라이벌에 대한 호감도는 -100~100입니다.
세부 조건과 수치 범위는 [한국어 설명](Intimacy-Affection-Guide-KO.txt)을 확인하세요.

기존 1.06.3 게임 데이터, 이미지, 193개 속옷, 라이벌 입상 16px 위치 수정과 다른 MOD 기능을 유지합니다.

검증: 완성 APK 자산을 Linux Godot으로 실행해 기존 기능 3,382개·새 기능 254개·재실행 유지 10개, 총 3,646개 검사를 통과했습니다. 터치 입력과 스크린샷도 확인했습니다.
APK 서명·기존 인증서 일치·ZIP CRC·16KB 정렬 및 공개 업로드 파일의 전체 재다운로드 SHA-256을 확인했습니다.
Android 실기기 검사는 수행하지 않았습니다. 검사 결과는 이 브랜치의 JSON 파일에 있습니다.
