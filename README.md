# Gensokyo MOD Android v0.11.0 r1

Gensokyo MOD Android 0.11.0 internal-r1

ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요.
기존 앱을 삭제하지 마세요. 저장/설정 메뉴에서 세이브 백업을 먼저 권장합니다.
동일 패키지·서명·저장 경로 / versionCode 26 / ARM64 / Android 7.0 이상.

MOD → 행동력·표정 → 원본·장면 표정 전체 보기:
미리보기를 길게 누르면 확대 및 제외/복원 확인창이 열립니다.
MOD → 추가 상황: 매일 무작위 조건 외형, 발생마다 무작위 표정,
의심/거리 두기, 비밀 연인 공개, 하우스 룰, 아이/미래 대화.
하우스 룰은 기본 꺼짐. 기존에 고정한 표정 선택은 보존됩니다.

APK 리소스를 Linux Godot에서 검사했습니다. 안드로이드 실기기는 미검증입니다.

대형 ZIP은 Git LFS로 저장합니다.
