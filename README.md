# 나라나 에디션 v0.14.0

나라나 에디션 0.14.0 internal-r1

ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요. 앱을 삭제하지 마세요.
기존 패키지·서명·저장 경로 유지, versionCode 45, ARM64, Android 7.0 이상.
다운로드는 Chrome에서 여세요.

MOD → 누나 왔다!
아래 항목을 각각 ON/OFF할 수 있습니다. 설정은 기기에 저장되어 재실행·세이브 변경 후에도 유지됩니다.
추천값으로 모두 켜기 / 모두 끄기는 기존 플레이어 행동 연동 스위치도 함께 변경합니다.
기존 행동 연동 스위치는 이전에 저장한 값을 유지합니다. 새 조절 기능은 기본 ON입니다.

추천 기본값
- 라이벌 호감도 획득 배율: 1.5배 (1~5배)
- 스킨십 / 키스 / 안기 선택 확률: 60% / 70% / 50%
- 헛행동 줄이기: ON. 유효 대상 재선정, 같은 시간대 거절 대상 재시도 억제.
- 적극성 강화: 대상 선택 가중치 1.5배 (1~3배)
- 기분 관리: 기분 40 미만이면 기존 이야기 들어주기 우선
- 자발적 휴식: 원래 확률의 50% (0~100%)
- 아이템 탐색: 하루 최대 5회 (1~20회)
- 규칙 제안: 기존 제안 기회에서 10%
- 모임 참석 우선: ON
- 주인공의 부탁에 아이템 대가 요구: 50%

확률은 기존 관계·수락·출입·수면 조건을 만족할 때 적용됩니다.
각 강화 항목을 OFF하면 해당 강화가 해제되고 원래 AI 동작을 사용합니다.
기존 AI가 원래 하던 행동 자체를 금지하는 기능은 아닙니다.
권유 → 키스 → 스킨십 순서로 자격을 확인하고 각각 확률을 판정합니다.

탐색은 기존 주인공 보상표를 재사용하고 획득 알림과 라이벌 보유 목록을 표시합니다.
일반 행동 기회 세 번당 최대 한 번 탐색하며, 모임 우선·수면·진행 중 선택창 등을 존중합니다.
일일 횟수는 상한이며 매일 그 횟수를 반드시 채우지는 않습니다. 실패한 탐색도 횟수에 포함됩니다.
전용 보유 목록에 저장하며 아이템 투여 행동을 새로 추가하지 않습니다.

아이템 대가는 라이벌에게 상황 묻기·대상 변경 부탁·손대지 말기 부탁에 적용됩니다.
수락할 때 표시된 아이템 한 개를 넘기고 원래 부탁을 실행합니다.
거절하거나 설정을 끄면 아이템을 넘기지 않습니다. 대가는 부탁 결과를 보장하지 않습니다.

기존 하우스 규칙·행동 연동·표정 수술/집합/제외/대체·메인 화면·동작 빈도 설정 유지.
최종 APK 리소스를 Linux Godot에서 실행한 자동 검사 516개 통과.
Android 실기기·에뮬레이터 설치 실행은 미검증입니다.

대형 ZIP은 Git LFS로 보관합니다.
