# Android MOD v0.3.0

[APK 다운로드](https://github.com/selecter1302-cloud/-/raw/refs/heads/gensokyo-android-v0.3.0/Gensokyo-Mod-Android-v0.3.0.apk)

기존 앱을 삭제하지 말고 APK로 업데이트 설치하세요. 동일 앱 ID와 서명을 사용하며 versionCode는 3입니다.
ARM64 Android 7.0 이상용. 본게임과 한국어 패치 포함.

- 우상단의 떠 있는 MOD 버튼 제거.
- 게임 자체 설정창 하단의 **MOD 설정** 버튼으로 모드 패널 열기. 모드창을 닫으면 설정창으로 복귀.
- 매번 앱 시작 시 행동력 최대치 고정과 일상 하트눈 끄기 자동 활성화. 실행 중에는 모드에서 변경 가능.
- **레이무 임신 시 임신 모습 자동 적용** 체크 옵션 추가. 매번 시작 시 켜짐.
  원본에 존재했으나 이후 패치에서 삭제 지정된 일반복·속옷·나체 임신 이미지 3장을 원본에서 복원.
  실제 임신 중일 때 현재 복장에 맞춰 일상 입상을 전환하며, 옵션 해제 또는 임신 종료 시 기본 모습 사용.
  임신을 새로 유발하거나 임신 판정/기간/대사/표정을 변경하지 않음.
- 호감도/라이벌, 표정 잠금, 원본 실신 활성화 유지. 사용자 지정 회복 기능 없음.
- 기존 16:9 화면 비율, 가로 방향, 몰입 전체화면 유지.

APK 서명, 동일 인증서, versionCode, ARM64, ZIP CRC, 16KB 정렬 검사 통과.
완성 APK 추출 리소스의 터치/UI/임신 전환 40개 및 기존 모드 996개 검사 통과.
기능 검사는 Linux Godot 4.6.3에서 수행. 실제 Android 기기 설치·실행은 미검증.
