# Android MOD v0.9.1 — 여성 라이벌 외형·한국어 호칭

[APK 바로 다운로드](https://github.com/selecter1302-cloud/-/raw/refs/heads/gensokyo-android-v0.9.1/Gensokyo-Mod-Android-v0.9.1.apk)

기존 앱 위에 업데이트 설치하세요. 앱을 먼저 삭제하면 내부 세이브가 지워집니다.
같은 앱 ID·서명, versionCode 14. ARM64 Android 7.0 이상.

## 변경

- 사용자가 제공한 여성 실루엣 PNG를 수정 없이 라이벌 입상으로 사용합니다.
- 얼굴 아이콘의 머리 표시 위치를 맞췄으며 도움말의 고정 게임 화면 2장도 갱신했습니다.
- 주인공의 남성 표현을 보존하면서 라이벌을 가리키는 한국어 남성 명사와 대명사를 골라 수정했습니다.
- 성격 표시: 다정한 남자 → 다정한 여자.
- 라이벌에 대한 성적 상태 문구 13곳: 남자 → 양성구유.
- 명시적으로 라이벌을 가리키는 부모 표현과 실제 혈연상 부모가 라이벌인 경우의 일부 엔딩 표시를 중립적으로 정리했습니다. 주인공이 해당되는 경우의 아버지 표현은 유지합니다.
- 기존 이름·기능·수치·행동·관계 판정·임신 판정·세이브 구조 및 MOD 설정은 유지합니다.

문구 변경은 한국어에 적용했습니다. 일본어·영어·중국어 번역은 유지합니다.
기존 세이브를 불러와도 새 외형과 문구가 적용됩니다. 새 게임을 시작할 필요가 없습니다.

기본 게임 데이터와 게임 동작 스크립트가 이전 버전과 동일함을 비교했습니다. 표시용 스크립트 2개만 조정했습니다.
최종 도움말 이미지 교체 후 검증된 APK와 비교하여 게임 코드·데이터가 동일함을 확인했습니다.
