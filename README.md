# 나라나 에디션 v0.12.2

나라나 에디션 0.12.2 internal-r1

ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요.
같은 패키지·서명·저장 경로 / versionCode32 / ARM64 / Android7.0 이상.
기존 앱을 삭제하지 마세요.

수정: 집안 규칙 「1일 1회 안기기」가 적용된 동안 라이벌이 아직 함께하지 않은
히로인을 우선 대상으로 선택하고 이동해 먼저 권유합니다.
라이벌 자신의 성욕 기준 때문에 권유하지 않던 조건을 이 전용 경로에서 제외했습니다.
각 히로인의 일반 수락·거절, 진행 가능 상태와 방 출입 제한은 확인합니다.
수동 조종·수면 설정은 유지합니다. 거절한 대상은 그날 다시 권유하지 않습니다.
성공 횟수는 히로인별·상대별 날짜로 저장하고 실제 장면이 시작될 때만 기록합니다.
라이벌은 히로인별 하루1회이며, 다음 날 다시 가능해집니다.
기존 권유·방문·대기 중인 새 시작에서도 하루 제한을 확인합니다.
이미 진행 중인 장면은 이 제한 때문에 중단하지 않습니다.
규칙 해제·만료 시 전용 우선 행동도 꺼집니다.
수락 가능 여부와 시간대·사건 진행에 따라 하루 안에 모두에게 권유하지 못할 수 있습니다.
추가 수정: 아침·점심 따로 먹기 규칙이 적용된 시간은 명령 판정에서도 자유 시간으로
처리해 창고 탐색·개별 행동이 식사 시간 제한으로 막히지 않도록 했습니다.
라이벌도 함께 있는 저녁 식사마다10% 확률로 규칙 제정 또는 폐기 투표를 제안합니다.
폐기 신청은 유지/폐기/기권 투표로 결정하며 단독으로 규칙을 없애지 않습니다.
같은 식사에서 재추첨·중복 제안하지 않습니다. 투표권·가중치는 기존과 같습니다.
폐기 부결 시 기존 규칙의 만료일을 연장하지 않습니다.
표정: MOD → 행동력·표정 → 각 캐릭터의 「H씬 표정 제외 / 복원」에서
원하는 화면을 고르고 미리보기 아래 「게임에 사용」 체크를 끄세요.
원본·추가 표정 및 다함께 안기 표정에도 적용하며 앱 재시작·세이브 변경 후에도 유지됩니다.
미리보기를 꾹 누르면 기존처럼 확대·제외/복원 창도 열립니다.
다함께 안기의 오른쪽 위 히로인이 단면도보다 위에 보이도록 수정했습니다.
암전·타이포와 일반 장면의 단면도 순서는 유지합니다.
0.12.1의 양쪽 협력자4종, 장부·UI·렌더링·슬라이더 수정을 포함합니다.

Linux Godot에서 최종 APK 리소스로 검사했습니다. Android 실기기·에뮬레이터 실행은 미검증입니다.

대형 ZIP은 Git LFS로 보관합니다.
