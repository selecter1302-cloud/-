# 나라나 에디션 v0.12.7

나라나 에디션 0.12.7 internal-r1

ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요. 앱을 삭제하지 마세요.
같은 패키지·서명·저장 경로, versionCode 38, ARM64, Android 7.0 이상.

수술♡에서 실제 대사·반응 분기에 표정 집합 연결
1. 원하는 인물에게 대화·칭찬 등 행동을 하고, 그 반응이 보일 때 수술♡ 작은 버튼을 누르세요.
   MOD → 표정 삽입-고정 수술♡에서 새끼버튼 표시를 켤 수 있습니다.
2. 게임이 실제 선택한 대사 항목과 선택 당시 조건 태그를 자동으로 기록합니다.
   인물·관계(공개/비밀 포함)·상대·평상시/장면·체위/배치 화면도 따로 구분합니다.
   같은 표정을 쓴다는 이유만으로 다른 대사 분기까지 바꾸지 않습니다.
3. 바로 열린 표정 집합에서 원래 표정과 원하는 후보를 최대 10개 고릅니다.
   원래 표정은 기본 포함입니다. 체크를 해제하거나 다시 넣을 수 있습니다.
   게임 기본 표정의 이름이 표시되며, 그림을 누르면 확대 미리보기가 열립니다.
4. 기본 선택 방식은 무작위입니다. 다음 행동에서 같은 분기가 다시 나오면 후보를 고릅니다.
   선택한 순서대로로 바꿀 수도 있습니다. 화면 갱신·편집창 열기는 교대를 진행시키지 않습니다.
   무작위 선택은 게임 시뮬레이션 RNG를 사용하지 않고 화면 갱신 중 다시 뽑지 않습니다.
5. 집합 저장을 눌러야 반영합니다. 취소는 저장하지 않습니다. 대체 안 함은 원래 표정을 유지합니다.
   저장 목록은 수술♡·표정 집합 두 MOD 탭에서 함께 편집/끄기/삭제할 수 있습니다.
6. 실제 출력된 반응을 포착하는 방식입니다. 모든 직접 문자열 출력 경로를 포착하지는 않습니다.
   포착되지 않은 화면은 대기 안내를 표시합니다. 이때는 원하는 행동 후 다시 누르거나
   원본 표정 기준으로 직접 편집 버튼으로 기존 수동 편집기를 사용하세요.
   세이브를 불러온 직후에도 새 행동을 한 뒤 실제 분기를 포착합니다.
7. 저장된 설정은 앱 재시작·세이브 변경 후에도 유지하며 내보내기/복원에 포함됩니다.
   관계가 바뀌거나 다른 게임 태그/대사 분기로 넘어가면 그 분기 설정을 적용하지 않습니다.
8. 새끼버튼 숨김과 저장한 표정 적용 OFF는 별개입니다. 적용 OFF는 설정을 삭제하지 않습니다.
   제외/OFF 표정은 후보에서 건너뛰고, 쓸 수 있는 후보가 없으면 안전한 원래 그림을 유지합니다.
   기존 항상 고정이 켜져 있으면 우선합니다. 편집기에서 해제할 수 있습니다.
   후배위는 제공된 그림에 분리된 얼굴층이 없어 원본을 유지합니다.

기존 표정 집합 탭의 원본 표정별/전체 집합, 세부 조건, 순서 교대도 유지합니다.
자동 포착 분기 규칙이 일반 원본 표정 규칙보다 우선합니다. 자동 포착 분기는 수동 조건 편집이 필요 없습니다.

최종 APK 리소스를 Linux Godot에서 실행해 검사했습니다.
Android 실기기·에뮬레이터 설치 실행은 미검증입니다.

대형 ZIP은 Git LFS로 보관합니다.
