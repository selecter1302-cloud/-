이전 모드 PCK를 제거하고 ZIP의 새 `ふしだら幻想郷_patch_1.04-1.05.9.5.pck`를 게임 EXE 폴더에 넣으세요. 기존 EXE, 원래 v1.05.9 한국어 패치와 저장 파일은 유지하세요. F3 → **호감도 · 라이벌** 탭에서 사용합니다.
