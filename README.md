## 수정

인게임 이동 화면의 라이벌 입상만 16픽셀 아래로 배치했습니다.
입상 하단이 화면 안에서 잘린 채 떠 보이는 부분은 화면 경계에서 자연스럽게 잘립니다.
얼굴 아이콘·상태창과 다른 히로인의 위치, 이미지 원본은 유지했습니다.
기존 193개 속옷, 표정, 라이벌 MOD, 설정과 세이브는 그대로 사용합니다.

## 확인

세 명이 있는 화면과 와이드 화면에서 수정 전후 좌표 및 스크린샷을 비교했습니다.
반복 갱신·화면 크기 변경·입상 효과 후에도 16픽셀 이동을 유지합니다.
얼굴 아이콘과 라이벌 상태창은 수정 전후 픽셀이 동일함을 확인했습니다.
모바일 UI 검사 40개 통과. APK 서명·기존 인증서 일치·ZIP CRC·16KB 정렬 확인.
완성 APK의 게임 데이터와 텍스처가 이전 버전과 같으며, 컴파일된 코드 변경이 표시용 파일 2개뿐임을 비교했습니다.
검수는 APK 자산을 Linux Godot으로 실행해 진행했습니다. Android 실기기 조작 검사는 미실시입니다.
