ZIP을 압축 해제하고 안의 APK를 설치하세요. 기존 앱은 삭제하지 말고 업데이트 설치하세요.
ARM64 Android 7.0 이상용. 같은 패키지/서명을 유지하며 설치 버전 번호는 5입니다.

## 변경 사항

- 게임의 사용 불가 버튼을 약 0.45초 동안 누르면 화면 아래에 게임의 사용 불가 사유를 표시합니다. 손을 떼거나 손가락을 벗어나면 숨깁니다.
- 당일 고백 거절 후 다시 고백할 수 없는 경우, 다음 날 다시 시도할 수 있다는 사유를 명시합니다. 한국어·영어·중국어 번역 포함.
- 휴대폰 화면 확대/여백 비율을 고려해 반복 입력은 현재 뷰포트 좌표로 처리합니다.
- 사용 가능한 일반 버튼은 약 0.45초부터 초당 최대 10회 반복 입력됩니다. 탭은 기존처럼 1회입니다.
- 스위치·체크박스·드롭다운·슬라이더는 기존 조작을 유지합니다. 손가락 이동, 다른 버튼으로 교체, 멀티터치, 앱 포커스 상실 시 반복을 중단합니다. 사용 불가로 바뀌면 동작 없이 사유를 표시합니다.
- 명령 패널이 새로 그려져도 같은 명령·대상·장소·시간인 경우 반복이 이어집니다. 게임의 사용 가능 판정과 일반 GUI 클릭 경로를 사용합니다.
- 게임 설정창 → MOD 설정 → 호감도 · 라이벌에서 각 히로인의 아래 4개 수치를 조절합니다.
  - 히로인 → 플레이어 호감도: -100~100
  - 히로인 → 플레이어 개발도: 0~100
  - 히로인 → 라이벌 호감도: -100~100
  - 히로인 → 라이벌 개발도: 0~100
- 슬라이더를 드래그하고 놓으면 적용됩니다. 레이무·사쿠야·마리사·사나에 순서와 캐릭터 색상을 유지합니다. 값은 일반 게임 저장/불러오기에 포함됩니다.
- 기존 시작 시 행동력 무한·일상 하트눈 끄기·레이무 임신 모습 자동 적용, 설정창 MOD 진입, 표정/라이벌 제어와 원본 실신 활성화 유지. 별도 회복 기능 없음.
- 16:9 가로 화면과 몰입 전체화면 유지.

## 검증

완성된 APK의 추출 리소스를 Linux Godot 4.6.3에서 검사했습니다.
새 입력/수치/실제 저장·불러오기 315개를 1280×720과 2400×1080에서 각각 통과. 기존 모드 996개, 모바일 UI 40개 통과(총 1,666개).
APK 서명·이전 앱과 인증서 동일성·versionCode·ARM64·ZIP CRC·16KB 정렬 검사 통과.
실제 Android 기기 설치·실행은 미검증입니다.
