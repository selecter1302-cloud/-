# Gensokyo Dialogue Editor v0.3.1

[사용자 수정 반영본 + Ctrl+H 편집기 ZIP 다운로드](https://github.com/selecter1302-cloud/-/raw/refs/heads/gensokyo-dialogue-editor-v0.3.1/Gensokyo-Dialogue-Editor-v0.3.1.zip)

첨부한 v0.3 수정 JSON을 반영했습니다. 본문 수정 32개는 모두 레이무·싫어함 범위이며, 사용 28개·제외 15개·미검토 1,189개를 보존했습니다.

전체 현재 본문을 `{name} 「대사」 {name}는 지문.` 형식으로 통일했습니다. 공백을 정리한 본문은 1,053개이며 이름 표식의 닫는 괄호 누락 한 곳도 복구했습니다. 다른 문구·문장부호·맞춤법은 임의로 바꾸지 않았습니다.

## 이어서 검토

ZIP을 풀고 `review/index.html`을 여세요. 수정 내용과 검토 진행 상태가 이미 반영되어 있습니다.
오른쪽 고정 ‘수정본 저장(JSON)’으로 받은 파일을 채팅에 첨부하면 됩니다.
`review/반영된수정본-v0.3.1.json`도 같은 반영 상태를 담은 저장 파일입니다. 기존 v0.3 JSON을 불러오는 것도 지원합니다.

## 전체 바꾸기

- Ctrl+H 또는 오른쪽 ‘모두 바꾸기’ 버튼.
- 전체 본문 또는 현재 필터 결과에 적용.
- 글자를 그대로 찾기, 대소문자 구분 선택, 변경 개수·예시 미리보기.
- 검토 결과·메모 유지.
- 마지막 일괄 변경 되돌리기. 이후 직접 수정한 본문은 덮어쓰지 않음.

## 검증

전 항목의 사용자 본문·검토 상태 보존을 대조했습니다. 실제 Chromium에서 Ctrl+H, 전체/필터 바꾸기, 되돌리기, 기존 JSON 가져오기, 저장·복원과 오른쪽 고정 버튼을 검사했습니다.
브라우저·데이터 검사 14개 및 별도 폴더에서 9개 검토 파일 재생성 일치 검사를 통과했습니다.
관리형 Chromium은 file://을 차단하므로 브라우저 검사는 임시 로컬 HTTP로 진행했습니다. HTML에는 외부 서버 호출이나 의존 파일이 없습니다.

APK는 수정하지 않았습니다. EXE·APK를 포함하지 않는 검토 편집기입니다. 기존 배포 브랜치는 덮어쓰지 않았습니다.
상세 검증은 VALIDATION.json, ZIP 체크섬은 SHA256SUMS.txt에 있습니다.
