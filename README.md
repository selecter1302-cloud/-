## 추가한 MOD

게임 설정 → MOD 설정 → 호감도 · 라이벌의 라이벌 설정 영역에 추가했습니다.
기존 「내가 고자라니!?」 임신 방지 토글은 계속 맨 아래에 있습니다.

- 「가장 좋아하는 상대 매일 변경」과 「현재 노리는 대상 매일 변경」 두 토글.
  - 기본은 꺼짐. 각각 독립적으로 켜고 끄며, 선택은 앱 재실행 후에도 유지.
  - 켜는 즉시 한 번 새로 고르고 이후 날짜가 바뀔 때 갱신.
  - 후보가 둘 이상이면 이전 상대를 제외하고 무작위로 선정. 후보가 하나면 유지, 대상 후보가 없으면 대상 없음.
  - 두 항목은 독립이므로 같은 날 같은 인물을 선택할 수도 있음.
  - 같은 날 일반 갱신이나 저장 불러오기로 재추첨하지 않음. 이전 세이브도 처음 초기화할 때 저장된 난수 상태로 재현 가능하게 처리.
  - 현재 노리는 대상은 일반 AI 목표 선택에 적용. 기존 보호 대상 제외, 명시적 지시, 수면, 수동 조종과 이동 제한은 유지.
- 라이벌 성기술 슬라이더: 1~100, E~A 등급 표시.
  - 손가락으로 드래그하고 놓으면 적용. 플레이어 성기술이나 시간/행동력은 변경하지 않음.
  - 「성기술 고정」을 켜면 일반 성장과 감소를 막음. 고정 중에도 슬라이더로 고정값을 다시 바꿀 수 있음.
  - 수치와 고정 여부는 일반 게임 저장에 포함.
  - 새로 저장한 성기술 1~5도 예전 등급 인코딩과 혼동하지 않고 정확히 복원. 기존 세이브의 등급 읽기 규칙은 유지.

기존 세이브 관계 표시, 임신 방지, 행동력/표정/호감도/개발도 기능, 관계 잠금 팝업 수정, 원본 실신 활성화와 화면 비율 설정 유지.

## 검증

완성 APK 추출 리소스를 Linux Godot 4.6.3에서 검사.
라이벌 새 기능 260개를 1280×720과 2400×1080에서 각각 통과. 엔진 재시작 복원 4개 통과.
기존 입력/저장/모드/모바일 UI 검사 1,974개 통과. 총 2,498개.
APK 서명, 동일 인증서, versionCode, ARM64, 16KB 정렬, ZIP CRC와 데이터 무결성 검사 통과.
실제 Android 기기 설치·실행은 미검증.
