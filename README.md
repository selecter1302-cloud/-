## 기존 설정값 확인·편집

게임 설정 → MOD 설정 → 「체력 · 실신」 탭을 추가했습니다.

- 「다수 절정 시 실신 ON / OFF」: 기존 기능의 플래그를 전환. 기본 OFF, 선택은 재실행 후에도 유지.
- OFF로 바꾸면 현재 남아 있는 실신 플래그와 대기 횟수를 정리하고 기존 회복값을 적용. 다른 수면 상태나 과거 기록은 변경하지 않음.
- 레이무 → 사쿠야 → 마리사 → 사나에 순서, 각 캐릭터 색상으로 표시.
- 캐릭터별 대상 체력과 회복 시 체력을 슬라이더 또는 숫자 입력으로 조절. 원래 값은 100 / 30.
- 각 값은 1~1000. 회복값은 시작 체력 이하로 제한.
- 진행 중인 대상이면 현재 수치에 즉시 반영. 나머지 캐릭터는 다음 시작 시 적용.
- 대상 체력 「고정」: 현재 값을 잡아 자동 소모·회복을 막음. 고정 중에도 값을 직접 다시 편집할 수 있음.
- 회복 시 체력 「고정」: 저장된 회복값을 재적용. 이전 저장에 다른 회복값이 있어도 고정값 유지.
- 두 값 모두 고정했다면 실제 현재 체력에는 체력 고정값이 우선.
- 설정값과 고정 여부는 앱 설정에 저장해 재실행·새 게임에도 유지.
- 진행 중 수치는 기존 게임 저장 안에 보관. 잠금이 없으면 해당 저장의 현재값 유지, 잠금이 있으면 설정된 고정값 적용.
- 게임 시간과 행동력은 설정 편집으로 소모하지 않음. 회상에서는 편집 불가.

v0.6.2의 옛 연인 관계 잠금 팝업 수정, 기존 협박 관계 잠금 팝업 수정, 세이브칸 손가락 스크롤과 다른 MOD 기능 유지.
원본 대사·이미지·게임 데이터는 변경하지 않았습니다.

## 검증

완성 APK의 리소스를 추출해 Linux Godot 4.6.3으로 검사했습니다.
1280×720과 2400×1080에서 새 설정 탭, 실제 터치 토글/슬라이더, 현재값 편집, 고정, 저장 복원과 엔진 재시작 설정 복원을 검사했습니다.
기존 MOD, 입력, 저장, 재시작 복원 회귀 검사를 포함해 총 2,877개 검사 통과.
APK 서명과 동일 인증서, versionCode, ARM64, 16KB 정렬, ZIP CRC 및 데이터 무결성 검사 통과.
실제 Android 기기 설치·실행은 미검증입니다.
