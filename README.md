# 나라나 에디션 v0.12.8

나라나 에디션 0.12.8 internal-r1

ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요. 앱을 삭제하지 마세요.
같은 패키지·서명·저장 경로, versionCode 39, ARM64, Android 7.0 이상.

이번 변경
1. 기존 표정 제외 화면에 각 표정의 대체 지정 버튼을 추가했습니다.
   지정 전에는 대체 지정, 지정 후에는 대체: 표정 이름으로 표시합니다.
   제외 안내창에서 대체 지정을 건너뛰었어도 나중에 이 버튼으로 지정할 수 있습니다.
   같은 캐릭터·같은 화면의 사용 가능한 표정만 후보에 표시합니다.
   대체 지정 해제는 대체 설정만 지우고 기존 제외 상태는 유지합니다.
   대체 설정은 해당 표정이 제외되어 있을 때 적용되는 기존 방식을 그대로 사용합니다.
2. 표정 삽입-고정 수술♡의 필터 순서를 모든 표정 / 기본 표정 / 추가 표정으로 바꿨습니다.
   열 때마다 모든 표정이 기본 선택됩니다.

3. MOD의 표정 삽입-고정 수술♡와 표정 집합 탭 맨 아래에 표정 모두 초기화 버튼을 추가했습니다.
   최종 확인창의 모든 표정 설정 초기화를 눌러야 실행됩니다. 취소하면 아무것도 변경하지 않습니다.
   네 캐릭터·모든 관계·화면/체위의 제외·대체·고정·집합·분기 연결과 추가 표정 설정을 기본값으로 되돌립니다.
   행동력·체력·호감도·관계·라이벌 및 의상·전용 외형 설정은 유지합니다.
   직전 설정은 기기 안 expression_reset_before.cfg에 한 번 백업합니다.

수술♡·표정 집합의 분기 연결·추첨·제외 적용 방식은 변경하지 않았습니다.
일반 화면과 장면/체위별 기존 제외 및 대체 설정 방식도 유지합니다.
분리된 얼굴층이 없는 화면은 원본 그림을 유지합니다.

최종 APK 리소스를 Linux Godot에서 실행해 검사했습니다.
Android 실기기·에뮬레이터 설치 실행은 미검증입니다.

대형 ZIP은 Git LFS로 보관합니다.
