## 라이벌 임신 방지 토글

게임 설정 → MOD 설정 → 호감도 · 라이벌 탭 맨 아래의 「내가 고자라니!?」.
- 켜기: 네 히로인 모두 라이벌에 의한 새 임신을 차단. 라이벌 자동/수동 행동에 공통 적용.
- 끄기: 원래 임신 규칙으로 복귀.
- 주인공의 임신 판정과 이미 발생한 임신은 변경하지 않음.
- 새 옵션의 기본값은 꺼짐. 켜고 끈 선택은 앱 재실행 후에도 유지하며, 다른 세이브를 불러와도 설정을 유지.
- 원래 임신 확률, 다른 수치, 행동 기록과 임신 판정용 난수 소모는 그대로 유지.

## 세이브·로드 관계 표시

날짜·시간 아래에 저장 당시의 레이무 / 사쿠야 / 마리사 / 사나에 → 주인공 관계를 추가.
일반 슬롯, 퀵세이브, 자동 저장에 공통 적용. 현재 플레이 중인 관계와 섞지 않고 각 파일의 기록을 읽음.
기존 세이브도 다시 저장하지 않고 바로 표시. 목록을 보는 것만으로 저장 파일을 수정하지 않음.
두 줄 터치 행과 스크롤 목록을 사용해 가로 화면 안에 배치. 빈 슬롯과 손상된 파일 처리는 기존대로 유지.
저장 형식의 버전은 변경하지 않음. 관계 정보가 없는 오래된 기록은 —로 표시.

기존 행동력/표정/호감도/개발도/라이벌 기능, 관계 잠금 팝업 수정, 임신 모습 전환, 원본 실신 활성화와 화면 비율 설정 유지.

## 검증

완성 APK 추출 리소스를 Linux Godot 4.6.3에서 실행해 검사.
새 기능 113개를 1280×720과 2400×1080에서 각각 통과, 엔진 재시작 설정 복원 2개 통과.
기존 잠금/입력/저장/모드 검사 1,746개 통과. 총 1,974개.
손가락 조작과 세이브 목록 스크롤은 터치 에뮬레이션으로 검사.
APK 서명, 동일 인증서, versionCode, ARM64, 16KB 정렬, ZIP CRC와 데이터 무결성 검사 통과.
실제 Android 기기 설치·실행은 미검증.
