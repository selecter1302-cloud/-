# Gensokyo Dialogue Editor v0.4.0

원본 APK의 말투와 죄책감 반응을 참고해 새로 쓴 784개 대사·지문 검토본이다. 라이벌이 현재 히로인의 연인인 상태에서 자발적으로 주인공과 외도한 이후만을 대상으로 한다. APK에는 아직 적용하지 않았다.

[ZIP 직접 다운로드](https://github.com/selecter1302-cloud/-/raw/refs/heads/gensokyo-dialogue-editor-v0.4.0/Gensokyo-Dialogue-Editor-v0.4.0.zip)

압축을 풀고 `Gensokyo-Dialogue-Editor-v0.4.0/review/index.html`을 연다. 오른쪽 고정 저장, Ctrl+H, 이름 삽입 버튼, 주인공·라이벌 이름 표식 일괄 변환을 사용할 수 있다. 각 항목에서 순정 대사를 비교할 수 있다. 이전 사용자 수정·검토 파일도 따로 보관했다.

실제 Chromium 기능 검증 12개와 616개 조건 조합 검사를 통과했다. ZIP 무결성·내부 파일 해시·별도 폴더에서 소스 재생성도 확인했다. `SHA256SUMS`와 `VALIDATION.json`에 결과가 있다. HTML 배포물이므로 EXE/APK는 포함되지 않는다.
