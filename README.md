# 나라나 에디션 v0.12.1

나라나 에디션 0.12.1 internal-r1

ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요.
같은 패키지·서명·저장 경로 / versionCode 31 / ARM64 / Android 7.0 이상.
세이브를 유지하려면 기존 앱을 삭제하지 마세요.

이번 수정
1. 몰표는 같은 편 상대와 연인·굴복 관계일 때만. 개발도만으로 몰표를 주지 않습니다.
2. 원본 협력 행동 4종을 양쪽에 연결: 평판 이야기, 대상 데려오기, 차·음료 제공, 발 묶기.
   MOD → 추가 상황 → 양쪽 협력자에서 4개 스위치와 주인공 편 목표를 설정합니다.
   모두 자동 행동입니다. 오늘 계획·대기 이유·최근 결과도 그곳에 표시합니다.
   주인공이 음료를 알아채면 거절 / 잔 바꾸기 / 마시기 선택창이 열립니다.
   발 묶기는 수락 / 거절. 라이벌이 대상일 때는 NPC 반응으로 처리합니다.
   양쪽 각각 하루 1회·최근 7일 3회. 음료·발 묶기는 각각 3일 간격입니다.
   기본 확률은 평판25%·데려오기20%·음료25%·발 묶기30%.
   협력자2명 +5%p, 3명 이상 +10%p, 최대35%입니다.
   협력자는 같은 편에서 매일30% 가입 판정, 다음 날부터 활동합니다.
   취기·행동 제한·다음 시간대 회복은 양쪽 공통입니다. 주인공은 자기 방에서 쉬어 회복합니다.
   공동방어의0.9와5% 거절 효과는 양쪽 실행 판정에 함께 적용합니다.
   주인공의 수동 선택에는 NPC 순위 점수가 없어 공통 실행 판정으로 연결했습니다.
   협정·협력자·거절 기록을 양쪽에 나눠 저장하고 원본 협력 결산 문구도 연결했습니다.
3. 곁의3명과 중앙 그림의 최종 이미지를 갱신 순간에 확정하도록 수정했습니다.
   원본을 보여 줬다가 타이머로 덧씌우던 중간 프레임을 제거했습니다.
4. 추가 상황 UI를 카드·2열 스위치·약48px 터치 영역으로 정리했습니다.
5. 라이벌 성기술 터치 드래그와 고정을 수정했고 장면 중에도 수치 조절이 가능합니다.
6. 공평장부·빚: 빚0일 때 갚기 기회를 먼저 쓰던 문제, 잠든 목격자 누적,
   장부OFF·집단 이탈 처리, 실제 친밀도 범위에서 나쁜 사이가2배 누적되지 않던 문제를 수정했습니다.
   MOD → 추가 상황 → 관계·공평 장부 → 누적 기록 보기에 실제 수치를 표시합니다.
   일반 교류 +1, 종료 기록 +2(시간대당1회), 최근3일 집계.
   빚은 같은 방 목격 +1(친밀도30이하 +2), 직접 교류 −2, 시간대당1회입니다.

기존 이미지·대사·표정·외형 공통 설정·저장 경로는 유지합니다.
진행 중인 사건이나 상태가 바뀌면 제안은 취소·보류될 수 있습니다.
검사는 Linux Godot/X11에서 진행했습니다. Android 실기기·에뮬레이터 검증은 아닙니다.

대형 ZIP은 Git LFS로 보관합니다.
