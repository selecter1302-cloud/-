## 관계 잠금 상태의 재결합 질문 수정

- 게임 자체 기능으로 플레이어와의 관계를 「옛 연인」으로 잠그면 재결합 질문을 생성하지 않음.
- 장면에서 이미 저장해 둔 질문 플래그도 최종 질문 생성 단계에서 다시 잠금을 검사.
- 잠금이 켜진 뒤 남아 있던 질문은 게임 상태 갱신 때 제거.
- 기존 세이브에 저장된 잠긴 관계의 재결합 질문도 불러올 때 제거.
- 이미 남아 있는 질문의 선택 처리는 잠금 상태에서 관계와 부가 수치를 변경하지 않음.
- 개별 잠금과 전체 잠금, 네 캐릭터 모두 적용. 잠금을 풀면 원래 질문 동작 복원.
- 다른 캐릭터나 수치의 잠금, 라이벌 쪽 관계 잠금은 플레이어 쪽 질문을 막지 않음.
- 기존 협박 관계 잠금 팝업 수정과 세이브 목록 손가락 스크롤, 나머지 MOD 유지.

이번 배포는 요청 중 관계 잠금 버그 수정만 포함합니다.
실신 ON/OFF 및 체력·회복값 조절 기능은 추가하지 않았으며 기존 관련 설정도 변경하지 않았습니다.

## 검증

완성 APK의 리소스를 추출해 Linux Godot 4.6.3으로 검사했습니다.
네 캐릭터의 잠금 상태에서 질문 생성, 캐시된 질문, 선택 처리, 개별/전체 잠금, 이전 저장 복원과 잠금 해제를 검사했습니다.
기존 MOD, 입력, 저장, 재시작 복원 회귀 검사를 포함해 총 1,310개 검사 통과.
APK 서명과 동일 인증서, versionCode, ARM64, 16KB 정렬, ZIP CRC 및 데이터 무결성 검사 통과.
실제 Android 기기 설치·실행은 미검증입니다.
