ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요. 앱을 삭제하지 마세요.
기존 패키지·서명·저장 경로 유지, versionCode 43, ARM64, Android 7.0 이상.

하우스 규칙 9종 점검 및 수정
- 가결 즉시 적용 → 다음 날 저녁까지 유지 → 다음 밤 식사 시작 때 만료.
- 기존 7일 규칙은 원래 가결·복원 날짜를 기준으로 이관하며 불러오기로 기간을 갱신하지 않습니다.
- 밤엔 문 안 잠그기: 밤·심야, 주인공·라이벌·히로인 개인 방에 적용. 다시 잠그기 방지. 욕실 사용 중 잠금은 유지.
- 속옷 규칙: 모임 종료 뒤 같은 방에 남아 있어도 규칙으로 바뀐 의상을 복원.
- 함께 한 잔: 실제 밤 모임 장소에 있는 주인공·라이벌·히로인에게 각각 하루 한 번 적용. 다른 방에는 적용하지 않음.
- 서로 스킨십 허용: 기존 하루 수치 +3(상한 적용), 권유 기본 확률 ×1.1. 기존 수락·거절 조건 유지.
- 사생활 존중: 밤·심야에 혼자 자기 방에 있으면 잠금. 히로인 야간 방문 차단, 일부 방해 행동 확률 절반.
- 아침·점심 모임 생략: 이동·탐색 보존. 원래 낮 모임이 없는 날은 점심 규칙의 눈에 보이는 변화가 없을 수 있음.
- 1일 1회 규칙: 인물·상대별 기존 횟수 제한 및 수락·거절·수면·출입 조건 유지.
- 음주 금지: 직접 음주·술 권하기 외 NPC의 식사 중 자발적 음주도 차단.
- 투표 결과와 상태 화면에 효과 및 정확한 만료 시점 표시.

MOD → 추가 상황 다음 탭 → 누나 왔다!
기본 꺼짐. 켜면 유효한 플레이어 행동마다 라이벌이 기존 AI로 한 번 행동합니다.
AP 5·1·0 및 무한 AP에 동일 적용. 기존 AP 틱과 겹친 이중 행동 방지.
수면·수동 조종·진행 중인 선택·대결 등 기존 진행 제한 유지. 잠든 밤에는 중지하고 다음 날 재개.
