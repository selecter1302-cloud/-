# 나라나 에디션 v0.12.0

나라나 에디션 0.12.0 internal-r1

ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요.
같은 패키지·서명·저장 경로 / versionCode 30 / ARM64 / Android 7.0 이상.
세이브를 유지하려면 기존 앱을 삭제하지 마세요.

밤의 공동 식사 → 교류 → 규칙 제안. 주인공만 하루 한 번 제안합니다.
같은 편 히로인은 주인공 또는 라이벌의 선택에 투표합니다. 중립은 무작위 선호로 투표합니다.
주인공 3표·라이벌 2표·히로인 각 1표. 최다 득표 동률에 주인공 안이 있으면 우선합니다.
누가 무엇을 선택했는지 결과 창과 아래 대화창에 공개합니다.
새 규칙: 아침 모임 없음 / 점심 모임 없음 / 1일 1회 안기기 / 음주 금지.
원본의 낮은 보통 개별 행동이며, 점심 모임 없음은 비 오는 날 낮 모임도 막습니다.
1일 1회 규칙은 편 소속과 무관하게 각 히로인과 주인공·라이벌 각각 하루 1회,
기존 routine 판정과 대사 태그를 재사용합니다. 자동 장면 시작이나 암시 저장값 변경은 없습니다.
실제 시작 때만 횟수를 기록하며 저장·불러오기에도 유지합니다.
수면·만취·협박 상태를 이 규칙으로 바꾸지는 않습니다.

목록 → 관계도 오른쪽 아래에 각 히로인의 편을 표시합니다.
기존 개발도 50 이상에서 더 높은 쪽, 동률은 기존 몸이 향하는 쪽, 그 다음 연인·굴복 관계 순입니다.
싫어함·협박 관계는 반대편을 우선하며 양쪽 모두 해당하면 중립입니다.
새로운 사랑 수치는 만들지 않았습니다.
공평 장부는 최근 3일, 양보의 빚과 양쪽 일반 교류 방어·협력자 기록을 추가했습니다.
협력자는 평판 이야기와 대화 자리 소개까지 적용했습니다. 음료·발 묶기 전체 이식은 포함하지 않습니다.

시작 중 다른 앱으로 나갔다 복귀하면 native 시작 초기화를 재시도하도록 추가했습니다.
실기기에서 검은 화면 재현·해결을 확인한 결과는 아닙니다.
기존 표정·외형 공통 설정과 저장 경로는 유지합니다.
소스 Godot 기능 검사 62개와 실제 클릭 UI 검사 21개 통과.
실행 검사는 Linux Godot/X11이며 안드로이드 실기기·에뮬레이터 실행 검증은 아닙니다.

대형 ZIP은 Git LFS로 보관합니다.
