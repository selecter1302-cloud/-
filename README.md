# F3 회복 버튼 모드 v1.5.0

[모드 ZIP 다운로드](https://github.com/selecter1302-cloud/-/raw/refs/heads/gensokyo-recovery-mod-v1.5.0/Game-Mod-Recovery-v1.5.0.zip)

기존 모드 PCK는 별도 보관하고 새 PCK를 Windows 게임 EXE 옆에 넣으세요.
본래 EXE와 원래 한국어 패치는 유지합니다. **F3 → 회복 → 회복~ 아프지마~**.
현재 장면의 히로인을 자동 선택하거나 레이무·사쿠야·마리사·사나에를 직접 고릅니다.

실신·자연 수면 해제와 endurance 복구를 수행합니다.
장면을 유지하며 다음 행동을 실행하거나 시간·AP·진행 횟수를 바꾸지 않습니다.
수면약 효과가 남아 있거나 회상 중인 경우에는 적용하지 않습니다.
기존 모드 기능도 포함했습니다. Android APK를 갱신하는 파일은 아닙니다.

실제 통합 PCK로 회복 검사 112개, 기존 기능 996개, 엔진 재시작 저장 복원 38개 통과.
Linux 엔진 검사 결과이며 Windows 실기기/렌더링 검증은 미실시입니다.
