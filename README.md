# 나라나 에디션 v0.11.2

나라나 에디션 0.11.2 internal-r1

ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요.
같은 패키지·서명·저장 경로 / versionCode 28 / ARM64 / Android 7.0 이상.
세이브를 유지하려면 기존 앱을 삭제하지 마세요.

밤에 모두 모여 식사하는 시간 → 교류 → 하우스 규칙 제안.
낮에 시작한 게임을 밤까지 진행해도 제안 버튼이 표시되도록 수정했습니다.
‘~랑은’ 관계 질문을 ‘~와/과’로 정리했습니다.
추가 공통 대사 97곳에 사쿠야 전용 존댓말을 적용했습니다.
히로인 둘의 짧은 반응은 연속 중복을 막고 두 사람이 번갈아 나오게 했습니다.
두 사람 사이에 들어가기 성공 시 두 사람 모두 자기 말투로 한마디 반응합니다.
표정 제외·기본/고정·표정 선택과 직접 고른 외형은 재시작/세이브 교체 후에도 유지됩니다.

APK 리소스를 Linux Godot/X11에서 실행해 검사했습니다.
안드로이드 실기기·에뮬레이터에서 설치 실행한 결과는 아닙니다.

대형 ZIP은 Git LFS로 보관합니다.
