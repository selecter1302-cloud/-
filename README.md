# 나라나 에디션 v0.12.3

나라나 에디션0.12.3 internal-r1

ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요.
기존 앱을 삭제하지 마세요. 같은 패키지·서명·저장 경로, versionCode33, ARM64, Android7.0 이상.

1. 대결: 시간대·날짜 변경을 이유로 라운드와 점수를 지우던 조기 종료를 제거했습니다.
   자정에도 대결 중이면 다음 날로 진행하며 라운드를 이어갑니다.
   대결 중 라이벌의 일반 AI가 별도 대상을 찾아가는 것도 막았습니다.
2. 표정: MOD → 행동력·표정 → 캐릭터의 표정 보기에서 화면을 고릅니다.
   기본 표정 / 추가 표정을 나눴습니다. 기본 표정의 추가 표정 연결 메뉴에서 여러 개를 체크하세요.
   기본 → 추가1 → 기본 → 추가2 순서입니다. 단순 화면 갱신으로는 순서가 바뀌지 않습니다.
   스탠딩, H씬 초상화, 체위별 장면, 다함께 안기 앞·뒤를 각각 따로 저장합니다.
   해당 화면에 연결을 만들면 기본 표정에 연결된 추가 표정만 교대로 표시합니다.
   연결을 모두 해제하면 이전의 상황별 자동 표정 동작으로 돌아갑니다.
   제외한 표정은 선택하지 않으며, 항상 고정 모드가 우선합니다.
   연결 설정은 앱 재시작·세이브 변경 후에도 유지됩니다.
3. 상시 외형: 실제 의복·속옷·나신 상태를 우선합니다.
   선택한 그림이 현재 옷차림에 맞을 때만 사용하고, 맞는 그림이 없으면 해당 옷차림의 원본을 표시합니다.
   매일 바뀌는 속옷도 상시 외형으로 덮지 않습니다.

0.12.2 수정 사항을 포함합니다. 관련 경로만 최종 APK 리소스로 Linux Godot에서 검사했습니다.
Android 실기기·에뮬레이터 설치 실행은 미검증입니다.

대형 ZIP은 Git LFS로 보관합니다.
