# 나라나 에디션 v0.12.5

나라나 에디션 0.12.5 internal-r2

ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요. 기존 앱을 삭제하지 마세요.
같은 패키지·서명·저장 경로, versionCode 36, ARM64, Android 7.0 이상.

새 기능: 표정 삽입-고정 수술♡
1. MOD → 표정 삽입-고정 수술♡ → 삽입-고정 수술♡를 누릅니다.
   MOD가 닫히고 현재 화면의 인물·표정 선택창이 열립니다.
   이후 그림 왼쪽 아래의 표정 고르기♡ 버튼으로 언제든 다시 엽니다.
2. 인물/화면을 고르고 기본·추가 표정 목록에서 그림을 누르면 크게 볼 수 있습니다.
   확대창의 확정을 눌러야 저장·반영됩니다. 확대·선택은 턴이나 행동력을 소모하지 않습니다.
3. 지금 나온 원본 표정일 때만 교체 / 이 관계·화면에서 항상 고정을 고릅니다.
   특정 원본 표정 교체가 전체 고정보다 우선합니다.
   인물·상대(주인공/라이벌)·관계(공개/비밀 연인 포함)·화면/체위를 각각 구분합니다.
   친구 때 저장한 설정은 연인 등 다른 관계에 적용하지 않습니다. 같은 관계로 돌아오면 다시 적용합니다.
4. MOD의 새끼버튼 표시를 끄면 작은 버튼만 사라집니다. 저장한 표정은 유지됩니다.
   저장한 표정 적용 OFF는 전체 수정을 중단하며, 각 목록의 스위치로 한 항목만 끌 수도 있습니다.
5. 저장 목록에서 적용 조건과 미리보기를 보고 수정·삭제할 수 있습니다.
   삭제에는 확인 절차가 있고, 수정/확대를 취소하면 원래 설정을 유지합니다.
   앱 재시작·세이브 변경 후에도 유지하며 세이브 내보내기/복원에 포함됩니다.
6. 기존 항상 고정·표정 제외·추가 표정 OFF 설정을 유지합니다.
   대상 표정이 제외/OFF이면 억지로 켜지 않습니다. 해당 설정을 먼저 조정하세요.
   후배위에는 제공된 자료에 독립된 얼굴층이 없어 원본 그림을 유지합니다.

0.12.4의 캐릭터별 평상/H씬 추가 표정 스위치, 관계·체위별 기본 교대 최대10개,
추가 연결 및 제외/대용 표정, 대결 시간 경과, 실제 옷차림 우선 처리도 유지합니다.

최종 APK 리소스를 Linux Godot에서 실행해 검사했습니다.
Android 실기기·에뮬레이터 설치 실행은 미검증입니다.

대형 ZIP은 Git LFS로 보관합니다.
