## PC 본판 1.06.3 통합

사용자가 제공한 「ふしだら幻想郷_patch_1.05-1.06.3」의 분할 ZIP 4개에서 PCK를 복원하고 원본 CRC와 모든 PCK 항목의 MD5를 검증했습니다.

- 본판 업데이트와 포함된 한국어 업데이트를 반영했습니다.
- 이전 본판, 새 본판, MOD v0.7.0을 비교해 세 방향 병합했습니다.
- 게임 데이터 JSON 94개를 새 본판과 대조했습니다. MOD 전용 안내 문구는 번역표에 추가로 유지했습니다.
- 새 본판의 능력치 불러오기 수정 반영: 실제 1~5 포인트를 옛 등급 값으로 확대하지 않고 그대로 복원합니다.
- 기존 MOD가 기록한 라이벌 성기술 포인트와 잠금도 유지했습니다.
- 행동력, 표정, 호감도/개발도, 라이벌, 체력·회복값·실신 설정, 관계 잠금 팝업 수정과 세이브칸 터치 스크롤 유지.
- 화면 비율, 전체 화면, 설정창 내부 MOD 메뉴, 앱 ID와 서명을 유지했습니다.
- 배포에 불필요한 원본 bug_reports 데이터와 스크린샷은 APK에 넣지 않았습니다.

기존 앱을 삭제하지 말고 업데이트 설치하세요. 이전 사용자 설정과 저장 경로를 유지합니다.

## 검증

완성 APK의 리소스를 추출해 Linux Godot 4.6.3으로 검사했습니다.
v0.7.0 엔진에서 직접 만든 이전 저장 형식 10개를 새 엔진으로 불러오고 다시 저장·복원하는 검사를 포함했습니다. 실제 사용자의 휴대폰 세이브를 받아 검사한 것은 아닙니다.
1280×720과 2400×1080의 MOD·터치 입력과 재실행 후 설정 복원도 검사했습니다.
기존 MOD, 입력, 저장, 재시작 복원 회귀 검사를 포함해 총 3,060개 검사 통과.
APK 서명과 동일 인증서, versionCode, ARM64, 16KB 정렬, ZIP CRC 및 데이터 무결성 검사 통과.
실제 Android 기기 설치·실행은 미검증입니다.
