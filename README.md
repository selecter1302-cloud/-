# Gensokyo Dialogue Editor v0.2.0

[Download the complete rewritten review and editor ZIP](https://github.com/selecter1302-cloud/-/raw/refs/heads/gensokyo-dialogue-editor-v0.2.0/Gensokyo-Dialogue-Editor-v0.2.0.zip)

원본 APK의 한국어 대사·지문과 복구한 GDScript를 다시 조사해 새로 쓴 검토본입니다. APK에는 아직 적용하지 않았습니다.
기존 v0.1.0 기본 발화를 재사용하지 않았고, 일반 출력에 덧붙였던 별도 속마음 항목을 제거했습니다.

## 직접 수정하는 방법

1. ZIP을 풀고 `review/index.html`을 브라우저로 엽니다.
2. 캐릭터·관계·몸 상태·시점·행동·수락/거절을 고릅니다.
3. ‘출력 본문’을 직접 수정하고 ‘사용/제외/미검토’와 메모를 남깁니다.
4. ‘수정본 저장(JSON)’으로 파일을 내려받아 채팅에 첨부합니다. 원본·수정본·문장 ID·조건·메모를 대조할 수 있습니다.
5. 나중에 이어서 작업할 때는 ‘저장본 불러오기’로 그 JSON을 엽니다.

브라우저 임시저장은 보조 수단입니다. HTML 파일 자체에 수정 내용이 저장되는 것은 아니므로 JSON 파일을 보관하세요.

## 포함한 결과물

- 레이무·마리사·사쿠야·사나에, 7관계, 2몸 상태, 직후·다음 만남·시간 경과와 행동 결과를 나눈 1,232개 완성 본문.
- 서로 다른 발화 후보 784개. B의 일부 발화는 같은 시점의 여러 행동에서 공유하고 지문은 다릅니다.
- 각 캐릭터 전체 Markdown, 편집 가능한 자체 포함 HTML, 기본 검토 JSON.
- 새 창작 원문, 생성·수정본 대조 스크립트, 원문 조사 및 분기 설계, 실행 검증 기록과 실제 브라우저 화면.

## 검증

조건·본문 누락 검사, 별도 폴더 재생성 및 7개 산출물 바이트 일치 검사를 통과했습니다.
실제 Chromium에서 직접 수정·미리보기·JSON 저장/불러오기·메모 복원·필터와 모바일 폭 레이아웃을 검사했습니다.
편집기와 분기 참조 모델의 23개 검사를 통과했습니다. 분기 참조 모델은 게임에 적용한 코드가 아닙니다.
관리형 Chromium은 file://을 차단하므로 브라우저 검사는 임시 로컬 HTTP로 진행했습니다. HTML에는 외부 의존 파일이나 서버 호출이 없습니다.
APK 패치·재빌드·서명·Android 기기 검증은 아직 하지 않았습니다. EXE·APK는 포함하지 않습니다.

상세 검사 범위는 VALIDATION.json, ZIP 체크섬은 SHA256SUMS.txt에 있습니다. 기존 배포 브랜치는 덮어쓰지 않았습니다.
