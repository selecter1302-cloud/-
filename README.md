# F3 모드창 v1.1.0

ZIP을 풀고 새 `ふしだら幻想郷_patch_1.04-1.05.9.2.pck`를 기존 게임 EXE와 같은 폴더에 넣으세요. 이전 모드 `ふしだら幻想郷_patch_1.05.9-1.05.9.1.pck`는 제거하세요. 게임을 다시 실행한 뒤 **F3**를 누르면 모드창이 열립니다. F3 또는 Esc로 닫습니다.

행동 수 회복, 일상 하트눈(원래 방식/연인일 때만/끄기)을 제공합니다. 기존 EXE와 한국어 패치는 유지하세요. 원본 EXE가 패치를 한 번만 읽는 문제를 해결한 한국어 통합 패치입니다. 게임 본편 EXE는 포함하지 않습니다. 제공된 v1.04 EXE + v1.05.9 한국어 패치용입니다.

원본 단일 패치 선택 로직으로 시작하는 과정과 실제 F3/Esc 입력을 포함한 Linux 헤드리스 검사 89개 통과. Windows 실기기 검증은 미실시입니다. 상세 안내는 ZIP에 포함되어 있습니다.
