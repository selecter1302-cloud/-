# F3 모드 v1.2.1 — 행동력 무한 상태의 시간대 전환 멈춤 수정

기존 모드 PCK를 제거하고 ZIP의 새 `ふしだら幻想郷_patch_1.04-1.05.9.4.pck`를 게임 EXE 폴더에 넣으세요. 기존 EXE와 원래 한국어 패치, 저장 파일과 설정은 유지하세요.

시간대 전환은 남은 AP를 0까지 소진하는 반복 처리를 사용합니다. 이전 행동력 고정이 이때도 AP를 최대치로 복구해 반복이 끝나지 않았습니다. 전환 중에는 원래 차감을 허용하고, 새 시간대에서 최대치 고정을 유지하도록 수정했습니다. 패키지에서 변경된 게임 파일은 state.gdc 하나입니다.
