# 나라나 에디션 v0.11.1

나라나 에디션 0.11.1 internal-r1

ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요.
같은 패키지·서명·저장 경로 / versionCode 27 / ARM64 / Android 7.0 이상.
세이브를 유지하려면 기존 앱을 삭제하지 마세요.

메인 표시를 나라나 에디션으로 변경했습니다.
MOD → 호감도·라이벌: 캐릭터별 관계 선택 → 관계 강제 적용.
MOD → 추가 상황: 차례 변경은 기본 12행동 대기 후 20% 확률로 자동 진행.
하우스 룰은 활성화되어 있으며 저녁 모임의 교류에서 투표를 제안할 수 있습니다.
화면 전환·표시 순서·대결 종료·추가 문구 표기를 수정했습니다.

APK 리소스를 Linux Godot/X11에서 실행해 검사했습니다.
안드로이드 실기기·에뮬레이터에서 설치 실행한 결과는 아닙니다.

대형 ZIP은 Git LFS로 보관합니다.
