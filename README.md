# 나라나 에디션 v0.12.4

나라나 에디션 0.12.4 internal-r1

ZIP을 풀고 APK를 기존 앱 위에 업데이트 설치하세요.
기존 앱을 삭제하지 마세요. 같은 패키지·서명·저장 경로, versionCode 34, ARM64, Android 7.0 이상.
업데이트 전 게임의 세이브 내보내기로 백업을 권장합니다.

MOD → 행동력·표정
1. 각 캐릭터의 평상 추가 / H씬 추가 스위치를 따로 설정할 수 있습니다.
2. 표정 보기에서 화면·체위, 관계, 기본/추가 표정을 선택하세요.
   모든 관계와 공개/비밀 연인을 구분합니다. 개별 설정이 없으면 공통 설정을 따릅니다.
3. 기본 교대를 최대 10개 체크하면 행동할 때마다 순서대로 바뀝니다.
   기본 표정의 추가 표정 연결에서 여러 개를 체크하면 기본과 추가가 번갈아 나옵니다.
   화면 갱신이나 불러오기만으로는 교대하지 않습니다. 항상 고정 설정이 우선합니다.
4. 표정을 제외하면 대용 표정 지정 여부를 묻습니다. 예를 누르고 후보를 선택하세요.
   대용을 지정하지 않아도 가능한 기본 표정으로 대체합니다.
   모든 후보를 제외하더라도 몸 전체를 숨기지 않습니다.
5. 캐릭터별·화면별·관계별 설정은 재시작과 세이브 변경 후에도 유지합니다.
   추가 표정 OFF는 저장한 기본 교대나 연결 목록을 지우지 않습니다.
   후배위는 제공된 그림에 분리된 얼굴층이 없어 원본 그림을 유지합니다.

이전 수정도 포함합니다.
- 시간대·날짜 변경 후에도 대결을 이어갑니다.
- 상시 외형은 실제 의복·속옷·나신 상태와 맞을 때만 적용합니다.
- 명시적으로 끈 설정을 재시작 시 다시 켜던 경로를 수정했습니다.
- 모드를 끄면 해당 모드의 예약 선택창·지속 효과도 중단합니다.
  이미 확정한 관계나 진행 기록을 되돌리지는 않습니다.
- 백업 복원 직후 표정·모드 설정도 바로 적용합니다.

최종 APK의 리소스를 Linux Godot에서 실행해 검사했습니다.
Android 실기기·에뮬레이터 설치 실행은 미검증입니다.

대형 ZIP은 Git LFS로 보관합니다.
