BLACK VEIL · 최후 방어선 — PIXEL NOCTURNE v0.5

1. ZIP 파일을 폴더에 압축 해제합니다.
2. BlackVeil.exe를 더블클릭합니다. 설치나 인터넷 연결은 필요 없습니다.

v0.5: 도트 분리 파츠·프레임 동작으로 재구성하고 전신 물결형 변형을 제거했습니다.
컬렉션 III 14벌을 추가해 세트 의상 총 42벌이며, 부위별 의상 40종을 재구성했습니다.
장신구 크기와 귀·목·가슴·손의 부착점을 수정하고 슬롯별·전체 해제를 추가했습니다.
기존 호감도 8단계·질문·선택지·선물·대화 기록과 새 의상 반응을 포함합니다.
이전 저장의 재화·연구·해금·전투·관계·대화·쉘터를 이어갑니다.

1–6 무기 선택 / 지도 위 +에 포탑 배치 / 포탑 클릭 강화·매각 / U 강화
SPACE 전투 시작·정지 / Q 지원 포격 / F 1~5배속 / F11 전체 화면
S 독대 쉘터 / ESC 뒤로·정지 / 독대 SPACE 또는 다음 버튼으로 대사 넘기기

의상실 → 컬렉션 I·II·III: 세트 의상 구매·착용.
의상실 → 부위별 커스텀: 상의·하의·이너 각각 구매·착용·해제.
미착용 부위는 불투명 기본 이너로 표시됩니다. 세트와 부위별 코디는 별도 착용 모드입니다.
장신구 관리: 슬롯의 해제 또는 모든 장신구 해제. 구매한 소유권은 유지됩니다.
장신구 목록은 좌우 드래그·휠·화살표로 이동합니다.
쉘터 → 질문하기 / 보좌관의 질문 듣기 / 선물 건네기로 상호 대화합니다.
질문 입력은 준비된 주제에 대한 오프라인 답변이며 AI 서비스와 연결하지 않습니다.
쉘터 꾸미기에서 가구를 구매하고 방 안에서 드래그하면 위치가 저장됩니다.
재화는 플레이로 획득하며 실제 결제 기능은 없습니다.

캐릭터는 2D 도트 분리 파츠 스프라이트입니다.
Windows 10/11 x64, OpenGL 3.3 지원 그래픽 드라이버가 필요합니다.
자동 저장 위치: %APPDATA%\BlackVeil\black_veil.json
Windows 실기기 실행은 아직 미확인입니다.
