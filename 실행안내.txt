BLACK VEIL · 최후 방어선 — HEART & MOTION v0.4

1. ZIP 파일을 폴더에 압축 해제합니다.
2. BlackVeil.exe를 더블클릭합니다. 별도 설치나 인터넷 연결은 필요 없습니다.
업데이트: 22개 본의 2D 리깅 · 부위별 의상 40종 · 호감 8단계 · 새 보좌관 대사 544개.
질문·답변·3지 선택지·첫 착용 반응·선물 감사·대화 기록·관계 에피소드를 추가했습니다.
기존 28벌·화염·산탄·5배속·여성 감염체·독대 쉘터와 꾸미기도 포함됩니다.
이전 버전의 자동 저장과 해금 정보는 그대로 이어집니다.

3. 하단 기관총을 선택한 뒤 지도 위 + 거치대에 포탑을 배치합니다.
4. SPACE로 웨이브를 시작합니다.

1–6 무기 선택 / 포탑 클릭 강화·매각 / U 강화 / Q 지원 포격
SPACE 전투 시작·정지 / ESC 뒤로·정지 / F11 전체 화면
F 1~5배속 / S 독대 쉘터 / 장신구 목록은 좌우 드래그 또는 휠
쉘터 꾸미기에서 가구 구매 → 방 안에서 드래그 → 위치 자동 저장
상단 의상실 → 부위별 커스텀에서 상의·하의·속옷을 각각 구매·착용·해제합니다.
해제 후에는 불투명 기본 운동복이 남습니다. 기존 세트 의상과 커스텀은 별도 착용 모드입니다.
쉘터 → 질문하기 / 보좌관의 질문 듣기 / 선물 건네기로 서로 이야기합니다.
독대에서 SPACE 또는 다음 버튼은 현재 대사를 표시하거나 다음 대사로 넘깁니다.
질문 입력은 준비된 주제별 답변입니다. 인터넷이나 AI 서비스 연결은 없습니다.
상단 연구소에서 영구 강화를 해금할 수 있습니다.
재화는 플레이로 획득하며 실제 결제 기능은 없습니다.

Windows 10/11 x64, OpenGL 3.3 지원 그래픽 드라이버가 필요합니다.
자동 저장 위치: %APPDATA%\BlackVeil\black_veil.json
전투·재화·의상·부위별 코디·장신구·연구·쉘터 가구·배치·조명이 저장됩니다.
호감·신뢰·편안함·관계 선택·대화 기록·미응답 선택지와 읽던 에피소드도 이어집니다.
